# KomoYa

## Alcance

KomoYa es un proyecto orientado a facilitar la gestión y el seguimiento de solicitudes de servicios de forma clara y accesible.

Este repositorio contiene el desarrollo incremental del sistema, incluyendo la evolución de sus funcionalidades, estructura y documentación.

## Contexto

El proyecto se desarrolla en el marco de ISW-912. Su propósito es servir como base de trabajo para analizar, construir y validar una solución centrada en las necesidades de sus usuarios.

Los cambios deben mantenerse alineados con el alcance definido para KomoYa y documentarse cuando aporten contexto relevante al equipo.
